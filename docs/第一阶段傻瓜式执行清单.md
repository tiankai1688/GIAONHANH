## ① 第一步：push 触发 CI 拿绿证（约 10 分钟）

### 情况 A：你已经有 GitHub 仓库

```bash
# 1. 打开命令行，进入这个文件夹
cd "C:\Users\kaiti\WorkBuddy\小时达软件开发"

# 2. 查看当前分支名（常见是 main 或 master）
git branch

# 3. 添加、提交、推送
git add -A
git commit -m "ci: enable pest + backend-smoke gates"
git push origin main        # 如果你的分支叫 master，就改成 origin master
```

### 情况 B：你还没有 GitHub 仓库（从零开始）

**步骤 B1：在 GitHub 上创建空仓库**
1. 打开 https://github.com/new
2. Repository name 填 `GIAONHANH`（或任意名字）
3. 保持 **Public**（免费跑 GitHub Actions）
4. **不要勾选** "Initialize this repository with a README"
5. 点击 **Create repository**
6. 创建后会看到一个页面，复制 HTTPS 链接，类似：
   ```
   https://github.com/你的用户名/GIAONHANH.git
   ```

**步骤 B2：在本地把代码推上去**

```bash
# 1. 进入项目文件夹
cd "C:\Users\kaiti\WorkBuddy\小时达软件开发"

# 2. 初始化 git
git init

# 3. 把 GitHub 仓库设为 remote（把下面 URL 换成你自己的）
git remote add origin https://github.com/你的用户名/GIAONHANH.git

# 4. 添加、提交、推送
git add -A
git commit -m "init: GIAONHANH first commit"
git branch -M main
git push -u origin main
```

推送后如果弹出登录框，按提示登录 GitHub。

### 看 CI 结果

1. 打开 `https://github.com/你的用户名/GIAONHANH/actions`
2. 等待 2–5 分钟
3. 应该会看到 4 个 job：
   - `contract`
   - `laravel`
   - `pest`
   - `backend-smoke`
4. **全绿 = ✅ 通过** → 截图保存到 `docs/evidence/ci-green.png`
5. **有红 = 把红色 job 的日志贴给我**，我负责定位修

## ② 第二步：本地跑后端并录真机视频（约 0.5 天）

### 启动后端

```bash
# 1. 进入项目文件夹
cd "C:\Users\kaiti\WorkBuddy\小时达软件开发"

# 2. 构建并启动（第一次会下载镜像，可能 5–10 分钟）
docker compose up -d --build

# 3. 等 MySQL 健康后，跑数据库迁移和种子数据
docker compose exec app php artisan migrate --seed

# 4. 验证后端真跑通了（应显示全部 PASS）
API_BASE=http://localhost:8080 node tools/backend-smoke.mjs
```

如果第 4 步显示 PASS，恭喜你——**后端确实跑起来了**。

1. **打开消费者 App**：
   - 直接双击打开 `C:\Users\kaiti\WorkBuddy\小时达软件开发\app\index.html`

2. **开始录屏**（Windows 按 `Win+G`，Mac 用 QuickTime）

3. **按这个顺序操作**（约 30 秒即可）：

## ③ 第三步：营收模型拍板（你 1 周内决定）

不需要写代码，只改 `backend/.env` 一行。你选哪个？

### 方案 A：维持 0 佣金（最诚实）
- 不改 `.env`，或加一行：
  ```
  PLATFORM_COMMISSION_RATE=0
  ```
- BP 写：先靠平台补贴跑规模，货币化靠增值服务/广告/会员

### 方案 B：收平台佣金（如 10%）
- 在 `backend/.env` 加一行：
  ```
  PLATFORM_COMMISSION_RATE=0.10
  ```
- 数字你定：8% / 10% / 15% 都可以

### 方案 C：混合模式
- 0 佣金 + 对商家券/会员收服务费
- 需单独沟通，我帮你写

**你只要在微信/这里回复我："选 B，10%" 这种格式**，我立刻帮你把 `.env` 写入，并更新 BP。
