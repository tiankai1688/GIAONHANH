## ② Docker 起服务 + 录真机视频（0.5 天，你执行）

```bash

# 4. 留压测底（scale 证据，跑 30s）
```

**方案 A · 维持 0 佣金（最诚实，当前默认）**
- 不动 `.env`（或显式 `PLATFORM_COMMISSION_RATE=0`）
- BP 中写明货币化路径：增值服务 / 广告 / 会员，而非交易抽佣

**方案 B · 收平台佣金（最直接）**
- `backend/.env` 加一行：`PLATFORM_COMMISSION_RATE=0.10`（示例 10%，你定具体数）
- `PaymentSplitService` 已读该值自动分账，无需改代码
- 适合：DD 里直接展示"take rate"

**方案 C · 混合**
- 0 佣金 + 只对商家券抽平台服务费，或会员订阅制
