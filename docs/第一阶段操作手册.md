## Step 2 — 本地起服务 + 录真机视频 + 留压测证据（🟡）

**前提**：本机已安装 **Docker Desktop** 并启动。

```bash
cd <你的仓库根目录>

# 1) 准备环境变量文件（若还没有 backend/.env）
cp backend/.env.example backend/.env
# 在 backend/.env 末尾追加一行，保证 smoke 里后台登录密码一致：
echo "ADMIN_SEED_PASSWORD=SmokeAdmin#2026" >> backend/.env

# 2) 构建并启动整栈（app:8080 + mysql + redis，mysql/redis 仅在 internal 网络）
docker compose up -d --build

# 3) 生成 key + 迁移 + 播种演示数据（首次必做）
docker compose exec app php artisan key:generate
docker compose exec app php artisan migrate --force
docker compose exec app php artisan db:seed --force

# 4) 确认服务起来了
curl -s http://localhost:8080/api/health        # 应返回 {"ok":true}

# 5) 跑端到端验证，导出日志作证据
mkdir -p docs/evidence
API_BASE=http://localhost:8080 ADMIN_PHONE=0900000001 ADMIN_PASSWORD=SmokeAdmin#2026 \
  node tools/backend-smoke.mjs 2>&1 | tee docs/evidence/smoke-local.log
# 预期末尾：RESULT: PASS (NN passed, 0 failed) ✅

# 6) 跑 30 秒 / 20 并发压测，导出证据（这是 DD 里 scale readiness 的诚实数据）
API_BASE=http://localhost:8080 DURATION=30 VUS=20 \
  node tools/load-test.mjs 2>&1 | tee docs/evidence/loadtest-local.log
```

**录视频**（只能你手动）：用 OBS / 系统录屏，按这条主链路走一遍，存 `docs/evidence/demo.mp4`：
> 首页 → 浏览商家 → 加购 → **跨店合并下单**（旗舰差异点）→ COD 支付 → 订单详情 → 后台结算列表

> 嫌手动敲命令麻烦，可直接跑我给的一键证据脚本：`bash tools/phase1-evidence.sh`（前提是 `docker compose up -d` 已起且健康）。

## Step 3 — 拍板营收模型（🟡）

代码已就绪，不需改业务代码，只改配置 + BP 叙事。

**选项 A：收平台佣金**（推荐融资时给明确货币化路径）
- 在 `backend/.env` 加一行：`PLATFORM_COMMISSION_RATE=0.08`（即 8%，按你定）
- `config/business.php` 已把 `commission_rate` 接到该环境变量，`PaymentSplitService` 会自动读——**零代码改动**
- 在 `docs/bp-honest-narrative.md` 写明：「平台抽成 X%，当前对商家 0 佣金为增长期策略」

**选项 B：维持 0 佣金，靠增值服务/广告/会员**
- `.env` 不改（默认 0）
- 在 BP 注明货币化路径：「增长期 0 佣金，货币化 = 广告位 + 会员免配送费 + 商家增值工具」

> 无论选哪个，**必须有一句可对外讲的货币化叙事**，否则「纯补贴 + 0 收入」在 DD 里是生存级风险。
